# akurganow.github.io

Personal CV of Alexander Kurganov, published at [akurganow.github.io](https://akurganow.github.io/).

Plain static HTML and CSS — no build step, no dependencies, no workflows.

- `index.html` — the CV itself
- `styles.css` — screen, print and dark-mode styles in one file

GitHub Pages serves the `main` branch as is (Settings → Pages → Deploy from a branch → `main` / root).
`.nojekyll` disables Jekyll processing so everything, including `.well-known`, is served verbatim.
